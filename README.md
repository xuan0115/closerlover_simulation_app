# 知己

网页版的模拟陪伴 App（项目文件夹叫「亲密爱人」）。借了「捡手机」的玩法：一台照 iOS 26 做的手机，锁屏上堆着她发来的消息，解锁后是桌面，主要在「chatwe聊我」里和她聊。

- 每天早上发早安，白天问你在干嘛，晚上道晚安
- **督促清单**（设置首页单独一栏）：要 TA 督促你做的事，默认是阅读和健身。每一项可以设哪几天、目标、提醒时间、关键词；到点 TA 在聊天里提醒你，桌面的打卡小组件按清单生成，打卡会自动发消息告诉 TA，聊天里说到关键词也会自动打卡
- 私聊给你发照片、小礼物，也会发朋友圈；会给你的朋友圈点赞、评论
- 语音消息和语音通话暂时标成「待开发」（`js/data/ui.js` 里 `FEATURES.voice` 改成 `true` 就打开）
- 「我的资料」：性别（女用「她」、男用「他」、非二元或自己填写用「TA」），星座默认天蝎座，身份选填
- 你可以设定人物的基本人设（名字、性别、星座、所在地）、社会人设（学历、专业、工作、家庭情况）、性格、你们的关系、TA 怎么叫你（「设置 → chatwe聊我」）。收入状况由程序生成，界面上看不到
- 两种回复方式：**固定模板**（不联网、不花钱）、**AI**（每句话都由 AI 按人设现想；第一次打开时会说明聊天会发去哪里）
- 「设置」最上面的「知己账户」：我的资料、邮箱和密码、云同步、数据与备份、退出登录
- 「设置 → 隐私与安全性」：说明知己里的 App 大多是模拟出来的，点它们时会发生什么（哪些会打开手机里真的 App）
- **回复节奏**（`js/core/rhythm.js`）：「设置 → chatwe聊我 → 陪伴方式」二选一。**真人作息**（默认）：按 TA 的作息（几点起、几点睡、工作日忙的时候，在「TA的人设 → TA的作息」里改）决定多久回，睡着了醒来才回，你连发 7 条能把 TA 吵醒；TA 说了晚安就当睡着了，说眯一会儿就睡一个小时左右；忙的时候过几分钟回，看不了手机的时候忙完才回；聊得正热时忙也会回。**24 小时陪伴**：什么时候都在几分钟内回。不管哪种，你说出想伤害自己这类话，TA 都马上回。每次回 1 到 4 条，打字有快有慢、偶尔停一下；你切走或关掉网页，到时间由锁屏通知替 TA 回，或者回来时按 TA 回复的时间补上
- **关系类型**：恋人或挚友（「设置 → chatwe聊我 → 你们的关系」），决定称呼、说话分寸、督促方式、台词和礼物。开始聊天以后就不能换了
- **英文模式**（「设置 → chatwe聊我 → 语言」）：chatwe 的界面和 TA 的消息都换成英文，陪你练英语；可选用词难度，AI 模式下 TA 会顺口纠正你的英文。手机其他地方仍是中文
- 人设、对话规则的依据和改动记录在《知己 · 陪伴对象设计规范》在线文档里：改规则先改文档，确认后再改代码

## 这台手机里有什么

- **开屏动画**：打开网页时先播一段，盖住加载时的黑屏：图标上的那台小手机出现，屏幕里亮起「知己 KNOWWO」，然后往屏幕里推（先慢后快），屏幕铺满后就是锁屏，大约 2.3 秒。网页没加载完时会停在「知己」亮着的画面等。从 iPhone 主屏幕打开时，系统先显示启动图（`assets/launch/`，就是「小手机亮着知己」那一帧），动画从这一帧接着推，大约 1.9 秒。`index.html` 里 `VER` 改成 1，推的时候「知己」会换成「欢迎来到知己」一个字一个字出现（旧的版本一，约 2.4 秒）。点一下能跳过；系统开了「减弱动态效果」时不推近、只淡出。动画写在 `index.html` 最前面，不用等其他文件。中文字形取自「有字库龙藏体」（Google Fonts 的 Long Cang），KNOWWO 取自 Cormorant Garamond，都是 SIL Open Font License 1.1，只把用到的几个字转成了图形，不用下载字体。
- **chatwe聊我**：这个项目自己做的聊天 App，照着常用聊天 App 的界面和操作做：聊天列表、置顶、免打扰、长按菜单（复制 / 转文字 / 引用 / 收藏 / 撤回 / 删除）、拍一拍、表情、相册、拍摄、礼物、学习 / 健身打卡、聊天背景、朋友圈（点赞、评论、自己发）、通讯录、发现、我、收藏、搜索。
- **设置**：照系统设置做。飞行模式、无线局域网（关掉时状态栏显示 5G）、专注模式（勿扰 / 个人 / 睡眠 / 工作）、电池（低电量模式）、墙纸、主屏幕与 App 资源库是真的能用的；其余几栏是样子。「督促清单」下面的「chatwe聊我」里是人设（基本人设 / 社会人设 / 性格 / 生活）、你们的关系、记得的事、什么时候找你、倒数日、照片池、回复方式、数据与备份。人物可以设成男性，界面上的「她」会跟着变成「他」。
- **仿真 App**：相机、计算器、照片、日历、备忘录，以及：
  - **时钟**：闹钟照 iPhone 做（左上「编辑」、右上「＋」，可设重复、标签、稍后提醒）。闹钟默认到点只响铃；打开「让 TA 提醒我」就改成 TA 在聊天里提醒。督促清单里的提醒时间也列在这里。晚上 8 点有一个预设闹钟「记得告诉自己/家人 我很爱你」，只能关，不能删。网页开着时才会响。
  - **天气**：显示 TA 所在地的真实天气（Open-Meteo，不用 Key）。
  - **语音备忘录**：样子，录音待开发。
  - 第三方 App（小红书、抖音……）：在 iPhone 上点图标直接打开手机里真的那个；在电脑上、或者手机里没装时，显示网页里它自己的页面。
- **App Store**：仿真的应用市场，图标是自己画的。在这里「获取」壳子（小红书、抖音、淘宝、哔哩哔哩……），删掉的 App 也能在这里重新下载。
- **苹果自带的几个**：照片、日历、备忘录等都是网页里的仿真页面，不跳转；只有**图书**和**播客**在 iPhone 上点会打开手机里真的那个（见下面「跳到真实 App」）。
- **桌面**：照 iPhone 出厂的样子排。第一页上面是「她的消息」和「倒数日」两个小组件，下面是 FaceTime、日历、照片、相机、邮件、备忘录、提醒事项、时钟、天气、TV、文件、App Store、地图、健康、钱包、设置；Dock 是 chatwe聊我、信息、音乐（没有 Safari，免得和网页本身搞混）。第二页是小红书、美团外卖、网易云音乐、豆瓣、微信读书、图书、播客、多邻国、小宇宙、企业微信、「实用工具」文件夹和打卡小组件。图标下面有名字；想要 iOS 26 那种不带名字的大图标，在「设置 → 主屏幕与 App 资源库」里选「大」。左右滑翻页时，搜索条会换成页码点。
- **编辑主屏幕**：在桌面上长按（电脑上也可以点右键），图标开始抖动，按住的那个可以直接拖走：拖动换位置、拖到 Dock、拖到屏幕边上翻页；点左上角的「−」删除 App 或小组件；左上角「＋」加回小组件；右上角「完成」。chatwe聊我、设置、App Store、相机、照片、信息、钱包、健康、查找删不掉。想复原：「设置 → 主屏幕与 App 资源库 → 恢复默认的桌面排布」。
- **墙纸**：「设置 → 墙纸」，和 iPhone 一样分锁定屏幕、主屏幕两张：可以选手机里的照片、她发过的照片、纯色或精选；主屏幕可以选「配对 / 模糊 / 颜色 / 照片」。默认的竹林是用代码画的。
- **图标**：都是通用图案（齿轮、信封、音符……）。每个图标可以在「设置 → 主屏幕与 App 资源库 → 某个 App」里换成你自己选的图片、改名字、改跳转地址。

## 跳到真实 App（只在 iPhone 上）

点图标时，网页让 iPhone 打开这个 App 的地址（URL scheme，App 在系统里登记的「门牌号」），和点一个链接一样，不附带任何信息。系统可能先问一句「要打开吗」；手机里没装的话会提示「网址无效」，然后回到网页里这个 App 的页面。

- **会跳转**：第二页和 App Store 里的第三方 App（地址写在 `js/data/ui.js` 的 `open` 里，比如小红书 `xhsdiscover://`、美团外卖 `meituanwaimai://`、网易云音乐 `orpheus://`），以及图书 `ibooks://`、播客 `podcasts://`。
- **不跳转**：其余系统 App（照片、日历、备忘录、时钟、天气……）打开的都是网页里自己做的页面。
- 想让某个系统 App 也跳转，在「设置 → 主屏幕与 App 资源库 → 某个 App」里给它填一个地址。

## 改台词

打开 `js/data/templates.js`：

- 每个场景是一组「说法」，每个说法是几条气泡：`['早安', '起床了没']`
- 可以用 `{称呼}` `{名字}` `{星座}` `{我的星座}` `{时段}` `{礼物}` 这些占位符
- `tease`（傲娇毒舌）、`sweet`（温柔体贴）、`genki`（元气黏人）三种性格各有专属说法，没写的场景用 `common`
- 文件最后的 `REPLY_RULES` 决定她怎么回你：按顺序匹配关键词，第一个对上的就用那组台词

## 怎么操作

- **回桌面**：点一下手机底部的横条，或者按住横条往上拖（电脑上用鼠标拖）。
- **返回上一级**：电脑上按 Esc；在 App 首页按 Esc 就回桌面；打开的文件夹按 Esc 关掉。
- **解锁**：锁屏上往上拖，或者点「向上轻扫以打开」。解锁后回到上次离开的地方：在和 TA 的聊天里锁屏或切走，解锁就是聊天（相机除外，回桌面）。点锁屏上 TA 的消息，直接进聊天。
- **长按消息**：手机上长按，电脑上点右键。双击她的头像是拍一拍。
- **语音**：输入栏左边切到「按住 说话」，按住录音，往上滑取消。浏览器会先问能不能用麦克风。她的语音用浏览器自带的朗读声音播放。

## 本地预览

直接双击 `index.html` 就能打开（麦克风、相机在这种方式下可能用不了）。最好起一个本地服务：

```sh
cd ~/Downloads/亲密爱人
python3 -m http.server 8000
```

然后打开 http://localhost:8000

## 在手机上打开

**临时看看（手机和电脑连同一个 Wi-Fi）**：在电脑上运行下面两行，然后在手机浏览器打开 `http://电脑的IP:8000`（第一行会打出 IP）。电脑开着、终端没关时才能用；这种 http 地址下，手机浏览器不让用麦克风和相机。

```sh
cd ~/Downloads/亲密爱人
ipconfig getifaddr en0 && python3 -m http.server 8000
```

**长期用：放到 GitHub Pages**，得到一个固定的 https 网址，麦克风、相机都能用；在 iPhone 上用 Safari「添加到主屏幕」后全屏打开，像个 App。

## 上传到 GitHub Pages

先在 GitHub 上新建一个空仓库（不要勾选自动生成 README），然后：

```sh
cd ~/Downloads/亲密爱人
git init
git add .
git commit -m "亲密爱人 网页版"
git branch -M main
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main
```

在仓库页面：Settings → Pages → Build and deployment → Source 选 **Deploy from a branch**，Branch 选 **main** 和 **/(root)**，保存。等一两分钟，网址是 `https://你的用户名.github.io/仓库名/`。

## 账号和云同步（Supabase）

- 网址：`https://app.knowwo.com`（GitHub Pages 绑的自己的域名，仓库根目录的 `CNAME` 文件写着它）。`knowwo.com` 本身留给以后的官网。
- 第一次打开：开屏后、解锁前，先是「你好」，再登录或注册知己账户。账户用邮箱：注册时给邮箱发一个验证码确认，之后用邮箱和密码登录；忘记密码也用验证码重设。连不上服务器时可以「先离线使用」。以后不再弹登录。
- 账户在「设置」最上面的卡片里（照 iPhone 的 Apple 账户做）：我的资料、邮箱和密码、云同步状态、数据与备份、退出登录。
- 登录后，聊天记录、设定、朋友圈会自动备份到云端（改动后 3 秒上传一次），换手机登录同一个账户就能接着聊。照片和墙纸只在本机。打开时先只问云端那份的时间，比这台手机上的新才下载。
- 隔一阵再打开时，要联网换一张新的登录通行证。连不上（网络慢、服务器在国外）就照常用，记录先存在手机里，连上后自动同步；不会在聊天中途弹登录框。登录真的失效了（很少见），设置最上面和桌面上的「设置」会出现红点，点进去重新登录。
- 以前只起了账号名的老账户（`名字@zhiji.app`，这个域名不是我们的）照样能登录，在「知己账户 → 邮箱」里绑定真实邮箱。
- 手机里已经有别的账户的记录、云端也有一份时，会问你用哪一份。
- API Key 不会上传到云端。
- Supabase 的设置：
  1. 后台 → SQL Editor，把 `supabase/setup.sql` 整段粘贴运行（可以重复运行）。它会让每个账号只能读写自己的存档。
  2. 后台 → Edge Functions → ai-proxy，用 `supabase/ai-proxy.ts` 替换代码；DeepSeek 的 Key 放在 Secrets 里，名字 `MY_SECRET_API_KEY`，不要写进代码。
  3. 发邮件：在 Resend 验证 `knowwo.com`，Supabase → Authentication → Emails → SMTP Settings 填 Resend 的发信设置（发件人 `no-reply@knowwo.com`）。不接自己的发信服务，Supabase 只能发给自己团队的人，每小时 2 封。
  4. Authentication → Sign In / Providers → Email：「Confirm email」打开；「Secure email change」关掉（老账户绑定邮箱时，旧地址 `@zhiji.app` 收不到信）。
  5. Authentication → Emails → Templates：照 `supabase/email-templates.md` 改三封邮件（注册、忘记密码、换邮箱），里面放的是验证码 `{{ .Token }}`。
  6. Authentication → URL Configuration → Site URL 填 `https://app.knowwo.com`。
- 你是数据库的管理员，技术上能看到所有人的云端存档。发给朋友用之前，要跟她们说清楚。
- 用云端存档覆盖这台手机之前，这台手机上云端没有的聊天会自动在本机备份一份（最多 3 份），在「数据与备份 → 找回被覆盖的记录」里能恢复。

## 锁屏通知（网页关着也能收到她的消息）

- 打开方法：登录、设好陪伴对象、第一次进到手机里时，会弹窗问一次要不要允许通知；以后在「设置 → 通知 → 允许通知」里开关。iPhone 要先在 Safari 里「添加到主屏幕」，从主屏幕的图标打开、登录，再开（需要 iOS 16.4 以上；没加到主屏幕时，弹窗会给添加的步骤）。电脑上的 Safari、Chrome 也能用。
- 原理：网页切走时，把她接下来 36 小时什么时候找你、你刚发的消息她什么时候回，连同设定和最近 40 条聊天，存到 Supabase 的 `push_plans` 表。Supabase 每分钟运行一次 `push-tick`，到点就用 DeepSeek 写好她要说的话（和网页里一样的设定、一样的规则），存进 `push_inbox`，再推到开了通知的手机上。下次打开网页，这些消息出现在聊天里。网页开着时不推，由网页自己发。
- 她连着主动找你 3 次你都没回，就不再追发（你让她提醒的闹钟除外）。网页里也是这样。
- 开着免打扰或专注模式时，消息照发，但不弹通知；飞行模式下她联系不上你。
- 用自己的 Key 时，服务器拿不到 Key，网页关着的这段时间她用固定模板说话。
- 「设置 → 通知」照 iPhone 的通知设置做：锁定屏幕 / 通知中心 / 横幅三种提醒、横幅风格（临时 / 持续）、声音、标记、显示预览（始终 / 解锁时 / 从不）。这些管的是知己这台模拟手机里的锁屏和横幅；其中「显示预览：从不」和「标记」也会用到真的锁屏通知上（只写「发来一条消息」、图标上不显示红色数字）。「通知中心」只是样子。
- 真的锁屏通知用的是手机默认的提示音；声音、震动在 iPhone 的「设置 → 通知 → 知己」里调。
- Supabase 的设置（做一次）：
  1. 后台 → SQL Editor，把 `supabase/push-setup.sql` 整段粘贴运行（要先运行过 `setup.sql`）。
  2. 后台 → Edge Functions → 新建一个函数，名字叫 `push-tick`，把 `supabase/push-tick.ts` 整个粘贴进去，部署；再在这个函数的设置里把「Verify JWT」关掉（定时任务不带登录凭证，函数自己检查暗号）。不用加新的 Secret，DeepSeek 的 Key 和 ai-proxy 共用；推送用的密钥第一次运行时自动生成，存在 `push_config` 表里。
- Supabase 免费版一周没人用会暂停，暂停后推送也会停，到后台点「Resume」就好。

## 只给自己看（不公开）

- 网页里加了 `noindex`，搜索引擎不会收录；但知道网址的人还是能打开。
- 别人打开你的网址，看到的是一台全新的手机，要注册自己的账号；看不到你的聊天记录和设定。
- 想让代码也看不见：仓库设成 Private，再用 Cloudflare Pages 之类连私有仓库发布（GitHub Pages 的免费版不能从私有仓库发布）。
- 完全不上网：在电脑上 `python3 -m http.server 8000`，手机连同一个 Wi-Fi 打开 `http://电脑的IP:8000`。只有你能看到，但电脑要开着，而且这种 http 地址下用不了相机。

## 隐私

- 没登录时，所有东西都只存在当前浏览器里。登录后，聊天记录、设定、朋友圈会备份到 Supabase；照片、墙纸、API Key 不上传。什么都不会传到 GitHub。导出备份也不含 Key。
- 仓库是公开的，`persona.js` 里写的东西别人能看到。跟你自己有关的设定，建议在网页「设置」里填。
- GitHub Pages 的网址里带着你的 GitHub 用户名。介意的话，用一个不暴露真名的账号来放，或者把仓库设为私有（私有仓库开 Pages 需要付费账号）。

## 接口说明（AI 模式）

- **知己内置 AI**（默认）：登录后直接能用，不用填 Key，走的是 Supabase 上的 ai-proxy 中转，用的是你的 DeepSeek 余额。每人每天限 200 次，在 `ai-proxy.ts` 开头改。
- **OpenAI**、**Gemini**：浏览器可以直接调用，但在国内需要能访问外网。
- **DeepSeek**：「服务」里选 DeepSeek，只要填 Key（在 platform.deepseek.com 的 API keys 页面创建，账户里要有余额）。接口地址和模型自动用 `https://api.deepseek.com`、`deepseek-flash`。聊天时会关掉它的「深度思考」，回得更快。
- **其他兼容接口**（通义、Kimi 等）：填接口地址、Key、模型名即可。个别服务不允许浏览器直接访问，会提示「连不上接口」。
- 「测试连接」用的是真正聊天时的设定，测通了聊天也就能用。聊天时出的错，会显示在「回复方式」页面最下面。
- 「AI 连不上时用模板顶上」默认打开：接口出错时 TA 用模板回你，不会冷场。
- 更新文件后，把 `index.html` 里所有的 `?v=1111` 改个数字（比如 `1112`），手机就会下载新文件，存着的旧版自动删掉。只改文件不改版本号，手机会一直用存着的旧文件。
- AI 生成照片每张要几十秒、按次收费。

## 现在做不到的

- **没开锁屏通知时，网页完全关掉就收不到她的消息。** 下次打开时，会把最近 12 小时内错过的消息补上（最多 3 条），锁屏上能看到。开了锁屏通知就能收到（见上面）。安卓手机在国内大多收不到网页推送（要用谷歌的推送服务）。
- 网页关着时她发不了照片和朋友圈、打不了电话，这些等你打开网页再补。
- 视频通话、发位置、发文件、表情包商店、群聊、红包和转账都没做。礼物只是一张小卡片，不涉及钱。
- 网页跳不进别的 App 里面，也读不到手机里真实的照片、日历、通知。
