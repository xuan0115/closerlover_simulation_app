# 亲密爱人

网页版的模拟陪伴 App。借了「捡手机」的玩法：一台照 iOS 26 做的手机，锁屏上堆着她发来的消息，解锁后是桌面，主要在「chatwe聊我」里和她聊。

- 每天早上发早安，白天问你在干嘛，到点提醒你去学习、去健身，晚上道晚安，睡前偶尔打电话
- 私聊给你发照片、语音、小礼物，也会发朋友圈；会给你的朋友圈点赞、评论
- 你可以设定人物的基本人设（名字、性别、星座、所在地）、社会人设（学历、专业、工作、家庭情况）、性格、你们的关系、TA 怎么叫你（「设置 → chatwe聊我」）。收入状况由程序生成，界面上看不到
- 三种回复方式：**固定模板**（不联网、不花钱）、**混合**（定时消息用模板，回你用 AI）、**全部用 AI**

## 这台手机里有什么

- **chatwe聊我**：这个项目自己做的聊天 App，照着常用聊天 App 的界面和操作做：聊天列表、置顶、免打扰、长按菜单（复制 / 转文字 / 引用 / 收藏 / 撤回 / 删除）、拍一拍、按住说话的语音消息、表情、相册、拍摄、语音通话、礼物、学习 / 健身打卡、聊天背景、朋友圈（点赞、评论、自己发）、通讯录、发现、我、收藏、搜索。
- **设置**：照系统设置做。飞行模式、无线局域网（关掉时状态栏显示 5G）、专注模式（勿扰 / 个人 / 睡眠 / 工作）、电池（低电量模式）、墙纸、主屏幕与 App 资源库是真的能用的；其余几栏是样子。最下面「App → chatwe聊我」里是人设（基本人设 / 社会人设 / 性格 / 生活）、你们的关系、记得的事、什么时候找你、倒数日、照片池、回复方式、数据与备份。人物可以设成男性，界面上的「她」会跟着变成「他」。
- **仿真 App**：相机、计算器、时钟（世界时钟、闹钟 = 她找你的时间、秒表、计时器）、照片、日历、备忘录。
- **其余图标是壳子**：在 iPhone 上点，会直接打开手机里真实的 App（见下面「跳到真实 App」）；在电脑上点，打开一张说明页。
- **桌面**：照 iPhone 出厂的样子排。第一页上面是「她的消息」和「倒数日」两个小组件，下面是 FaceTime、日历、照片、相机、邮件、备忘录、提醒事项、时钟、天气、TV、文件、App Store、地图、健康、钱包、设置；Dock 是 chatwe聊我、Safari、信息、音乐。第二页是小红书、美团外卖、网易云音乐、豆瓣、微信读书、图书、播客、多邻国、小宇宙、企业微信、「实用工具」文件夹和打卡小组件。图标下面有名字；想要 iOS 26 那种不带名字的大图标，在「设置 → 主屏幕与 App 资源库」里选「大」。左右滑翻页时，搜索条会换成页码点。
- **墙纸**：「设置 → 墙纸」，和 iPhone 一样分锁定屏幕、主屏幕两张：可以选手机里的照片、她发过的照片、纯色或精选；主屏幕可以选「配对 / 模糊 / 颜色 / 照片」。默认的竹林是用代码画的。
- **图标**：都是通用图案（齿轮、信封、音符……）。每个图标可以在「设置 → 主屏幕与 App 资源库 → 某个 App」里换成你自己选的图片、改名字、改跳转地址。

```

css/

  ios.css               设置、相册、墙纸页的样式
  wechat.css            chatwe聊我 的样式（聊天、语音、朋友圈、资料页……）
  call.css              语音通话界面
  extra-apps.css        日历、相机、备忘录、计算器、时钟
  overlays.css          通知横幅、底部面板、提示
js/
  data/                 ← 不懂程序也能改的部分
    ui.js               有哪些 App、跳转地址、桌面怎么排、文件夹、精选墙纸

    zodiac.js           12 星座：日期、印象、她聊到星座时说的话
    templates.js        固定回复模板：三种性格 × 各种场景，加关键词规则；礼物清单
    prompts.js          AI 模式下给模型的说明
    providers.js        回复方式说明、模型服务默认值
  core/                 工具、存储、定时
  ai/                   templates.js 模板引擎 / llm.js 调接口 / brain.js 决定说什么
  ui/                   icons.js 图标 / wallpaper.js 墙纸 / shell.js 外壳、桌面、手势 /
                        wechat.js chatwe聊我 / voice.js 语音和通话 / photos.js / plans.js /
```

**注意**：第一次打开后，设定就存进浏览器了，之后以网页「设置」里的为准，再改 `persona.js` 不会覆盖。想让改动生效，在网页「设置 → chatwe聊我 → 数据与备份 → 全部恢复默认」，或者直接在网页里改。`templates.js`、`zodiac.js`、`prompts.js`、`ui.js` 不受影响，改了刷新就生效。

## 改台词

打开 `js/data/templates.js`：

- 每个场景是一组「说法」，每个说法是几条气泡：`['早安', '起床了没']`
- 可以用 `{称呼}` `{名字}` `{星座}` `{我的星座}` `{时段}` `{礼物}` 这些占位符
- `tease`（傲娇毒舌）、`sweet`（温柔体贴）、`genki`（元气黏人）三种性格各有专属说法，没写的场景用 `common`
- 文件最后的 `REPLY_RULES` 决定她怎么回你：按顺序匹配关键词，第一个对上的就用那组台词

## 怎么操作

- **回桌面**：点一下手机底部的横条，或者按住横条往上拖（电脑上用鼠标拖）。
- **返回上一级**：电脑上按 Esc；在 App 首页按 Esc 就回桌面；打开的文件夹按 Esc 关掉。
- **解锁**：锁屏上往上拖，或者点「向上轻扫以打开」。
- **长按消息**：手机上长按，电脑上点右键。双击她的头像是拍一拍。
- **语音**：输入栏左边切到「按住 说话」，按住录音，往上滑取消。浏览器会先问能不能用麦克风。她的语音用浏览器自带的朗读声音播放。

## 本地预览

直接双击 `index.html` 就能打开（麦克风、相机在这种方式下可能用不了）。最好起一个本地服务：

```sh
cd ~/Downloads/亲密爱人
python3 -m http.server 8000
```

然后打开 http://localhost:8000

## 在手机上打开

**临时看看（手机和电脑连同一个 Wi-Fi）**：在电脑上运行下面两行，然后在手机浏览器打开 `http://电脑的IP:8000`（第一行会打出 IP）。电脑开着、终端没关时才能用；这种 http 地址下，手机浏览器不让用麦克风和相机。

```sh
cd ~/Downloads/亲密爱人
ipconfig getifaddr en0 && python3 -m http.server 8000
```

**长期用：放到 GitHub Pages**，得到一个固定的 https 网址，麦克风、相机都能用；在 iPhone 上用 Safari「添加到主屏幕」后全屏打开，像个 App。

## 上传到 GitHub Pages

先在 GitHub 上新建一个空仓库（不要勾选自动生成 README），然后：

```sh
cd ~/Downloads/亲密爱人
git init
git add .
git commit -m "亲密爱人 网页版"
git branch -M main
git remote add origin https://github.com/你的用户名/仓库名.git
git push -u origin main
```

在仓库页面：Settings → Pages → Build and deployment → Source 选 **Deploy from a branch**，Branch 选 **main** 和 **/(root)**，保存。等一两分钟，网址是 `https://你的用户名.github.io/仓库名/`。

## 隐私

- API Key、聊天记录、朋友圈、照片、墙纸、你在网页里填的设定，都只存在当前浏览器里，不会上传到 GitHub。导出备份也不含 Key。
- 仓库是公开的，`persona.js` 里写的东西别人能看到。跟你自己有关的设定，建议在网页「设置」里填。
- GitHub Pages 的网址里带着你的 GitHub 用户名。介意的话，用一个不暴露真名的账号来放，或者把仓库设为私有（私有仓库开 Pages 需要付费账号）。

## 接口说明（混合 / AI 模式）

- **OpenAI**、**Gemini**：浏览器可以直接调用，但在国内需要能访问外网。
- **其他兼容接口**（DeepSeek、通义、Kimi 等）：填接口地址、Key、模型名即可。个别服务不允许浏览器直接访问，会提示「连不上接口」。
- 「AI 连不上时用模板顶上」默认打开：接口出错时她用模板回你，不会冷场。
- AI 生成照片每张要几十秒、按次收费。
