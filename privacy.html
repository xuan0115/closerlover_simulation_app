来自开发者的话 「知己 Knowwo」是一个陪你打卡、与你聊天、共同成长的AI陪伴网页应用，由开发者xuan开发与维护（下称「我」）。以下用最直白的话语说明：你的数据如何收集、储存、以及你可以如何处理它们。

隐私政策 Privacy Policy

一、我会收集与存储什么

  • 不登录时（本地模式）：你创建的人设、聊天记录、备忘录、朋友圈动态及个人设置（含自填的 API Key），全部只保存在当前设备的浏览器中，不会上传到我的云端服务器。清理浏览器缓存或换设备会导致本地未备份数据丢失。
  • 注册并登录后（云端同步模式）：记录你的登录账号标识（如邮箱或自定义账号）及加密凭证；当你使用云端备份与同步时，你的角色设定、聊天记录与配置会作为存档保存在云端数据库中，以便跨设备恢复。
  • 照片：你发的照片、头像和墙纸只存在当前设备里，不会上传到云端。
  • 锁屏通知（你打开后才有）：为了在网页关着时，TA 也能按时找你、回你的消息，云端会保存一份「接下来要发的消息」计划，里面有角色设定和最近的一段聊天记录，以及你这台设备的推送地址。通知经由 Apple、Google 等系统推送服务送达，内容在传输中是加密的。所有设备都关掉通知后，这份计划会被删除。
  • 注册邮箱：注册、找回密码、更换邮箱时，验证码邮件由邮件服务 Resend 代为发送。它只会拿到你的邮箱地址和这封邮件，用来把信送到你手里。
  • 天气：小手机里的天气 App 会把 TA 所在的城市名发给 Open-Meteo 查询天气，不带你的账号信息。
  • 基础运行日志：网站托管服务（如 GitHub Pages、Cloudflare）与后端基础设施在提供传输时，会自动产生基础访问日志（如请求时间、IP 地址），仅用于保障服务安全与防刷限流。

二、AI 对话数据是如何处理的

为了实现虚拟伴侣的回复，你的对话上下文需要发送给大语言模型（LLM）处理：

  • 使用「知己内置 AI」时：你发送的消息、角色设定及必要上下文，会通过 HTTPS 加密通道经由我的云端安全代理转发至第三方大模型服务商（如 DeepSeek API）生成回复，你的信息只会发给 DeepSeek 生成回复，不会给其他人。网页关着时（开了锁屏通知），TA 的回复也是由云端按同样的方式生成的。
  • 使用「自填 API Key」时：请求由你的浏览器直接加密发送至你所选定的服务商接口（如 OpenAI、Gemini、DeepSeek 等），你的密钥与实时对话完全不经过我的服务器中转，只会存储在你的手机/浏览器中。

三、数据放在哪里，谁能接触到

  • 存储位置：云端同步数据保存在由 Supabase 提供的云端数据库中，该服务器位于中国大陆之外，使用云同步即代表你知晓并同意该跨境传输。
  • 安全隔离：所有通信均采用 HTTPS 加密；数据库启用行级安全策略（RLS），每个账号只能读写自己的存档。
  • 坦诚说明：云端存档目前未做端到端加密。作为开发者，我在后台拥有数据库维护权限；但我承诺：除响应你的主动求助或排查故障外，绝不会主动查看你的私人对话，更不会向任何第三方出售、出租或共享你的数据。

四、数据保存多久与你的掌控权

  • 随时导出备份：你可以在小手机的「设置 → 知己账户 → 数据与备份」中，随时将全部人设与聊天记录导出为本地 JSON 文件。
  • 清空与注销：你可以随时在应用内重置本地数据，或通过下方邮箱要求彻底注销云端账号并永久删除云端存档。

五、年龄限制（仅限成年人）

本应用包含开放式人工智能角色扮演与虚拟情感陪伴功能，仅面向年满 18 周岁的成年用户提供服务。未满 18 周岁请勿注册或使用。
